# Prism: project brief

Read this first. It is the one page needed to pick the project up cold. Keep it current: when something here changes, change it in the same PR. Last checked against the code on 23 Nov 2026 (app and Sheet script **0.3.1**).

## What it is

A production tracker for a small chemical factory in India. Two Hindi-speaking workers and an owner/admin use it on their phones.

- **Prism** (worker app, Android): log **batches made** (raw material use is worked out from the recipe) and **waste / spills**. Entries can be edited, deleted or undone the same day. Offline-first.
- **Prism Admin** (admin iPhone, `/admin`): opens on **Reports**, plus **raw material stock** (add/remove in kg or containers, low-stock alerts) and a **Recipes** screen.
- **Google Sheet "Prism Production"** is the shared database, through an Apps Script web app. It sends a **daily email report** (after 20:00 IST), **low-stock alerts**, and a **weekly CSV backup by email** (Sundays).
- English and Hindi, dark and light themes. Web app now, Android app later.

## Design rules

- **Look:** "dark glass" by default, with a light theme (`data-theme="light"`). All colours are tokens in `app/css/app.css`; neon colours used as text get a darker shade in light mode so they stay readable.
- **Menus and flow:** "Who are you?" → Home with three big buttons: **Batches made**, **Waste / Spill**, **Today's entries**. Admin opens on **Reports**. Each screen is a `#/name` address, so the Android back button steps back one screen.
- **Tones per flow** (accent colour): batches and recipes green `#00F5A0`, waste orange `#FF9F00`, log and stock blue `#3D8BFF`, reports purple `#A855F7`, home/settings/who slate.
- **Backdrops:** a soft aurora gradient behind every screen, tinted by the current tone. Top bar, dialogs and toasts are blurred glass.
- **Material colours** by the first letter of the code: R red, Y yellow, S white, P purple, each code its own shade. Products use their own colour, else their category colour, else an automatic neon.
- **Big targets:** 56 px main buttons, nothing under 44–48 px, smallest report text 13 px. Labels in both languages.
- **Hindi:** no letter-spacing or capitals (they break Devanagari). One wording per term everywhere.
- **Icons:** thin 24×24 line icons in `app/js/icons.js`, drawn in the current text colour.
- **Art:** home-screen icons are a faceted glass prism. Prism splits a white beam into the app's three neon colours; Prism Admin throws a wide rainbow. Drawn by `tools/shortcuts/draw_icons.swift`.

## Decided, don't reopen

- **Backups go by email, not Drive.** A Drive copy needs "all of your Drive files" permission.
- **No `--demo` switch.** The website can never carry recipes, names or the key. Products come from the Sheet and are managed in Prism Admin → Recipes.
- **The Sheet wins** over `config.json` once connected.
- Workers change only **today's entries on their own phone**. Older fixes are made in the Sheet, and amounts follow the correction.
- Delete and Undo are **soft** (marked deleted, audit trail kept). The server dedups by Entry ID and newest `updatedAt` wins.
- **Stock left = added − removed − used in batches − wasted.** Each entry uses the recipe as it was on its day. A spoiled batch marked "already recorded" counts as waste but isn't taken off stock again.
- Phones install the website to the home screen. No app store.
- Browser tests for the phone screens (#11) are **parked** by the owner.
